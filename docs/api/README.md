# Tài liệu API

Backend dùng FastAPI; router ứng dụng được gắn dưới `/api/v1` trong [main.py](../../apps/backend/main.py).

- [Xác thực và phân quyền](authentication.md).
- [Tra cứu endpoint và request/response](endpoints.md).
- [README backend](../../apps/backend/README.md): hướng dẫn chạy và mô tả nghiệp vụ hiện có.
- [Quy tắc dữ liệu](../product/business-rules.md).

Khi backend đang chạy, truy cập `/docs` để thử API, `/redoc` để đọc đặc tả hoặc `/openapi.json` để lấy schema theo cấu hình triển khai. OpenAPI phản ánh phiên bản backend đang chạy.
